## Why

Same-bundle drift today (`combined` 31.3–40.5 s/token across three runs depending on background load) is as large as the fixes under test, so the
sequential 3+1 rows cannot separate a 3 s/token fix from a load swing. Here every candidate run is paired with a `combined` (ref) run taken immediately
before it, so both see the same machine state within ~10 min; the statistic is the paired difference, not the absolute number.
