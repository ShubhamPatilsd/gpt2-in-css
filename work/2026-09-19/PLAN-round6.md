# Round 6 plan (2026-09-30) — make `combined8-c32` a shareable demo: free-text prompt, visible progress, faster load

Base: `bundles/combined8-c32` (cap 32, 32/32 on prompt 40, 905.6 s) and `bundles/combined8` (cap 8). Emitter: R5X/tools.
Constraints unchanged: zero JS, no model change, stock Chrome, exact ids (dropdown prompts must keep matching their references;
new free-text prompts get their own NumPy reference). Machine gate before any Chrome: AC AND ((disk ≥ 4 GB AND swap < 4,000 MB)
OR (disk ≥ 3 GB AND swap < 3,000 MB)); CHROME.lock protocol; one build at a time; never build during another agent's Chrome run.

User-reported issues (2026-09-30, viewing combined8-c32 in their own Chrome via the --no-open server):
1. Selecting a prompt in the dropdown ("A") does not visibly change anything; the output area shows "!" (GPT-2 id 0).
2. Wants to type a prompt in a textbox, as `tinystories/dynamic.html` allows (editable `<style>`, OpenType BPE tokenizer fonts →
   token ids as glyph widths → first ≤4 tokens prefilled, then generation).
3. Wants a visual indication of progress toward the next token (progress bar / countdown).
4. Load takes ≈34 s with a blank spinning tab; wants it faster and shareable with other people.
