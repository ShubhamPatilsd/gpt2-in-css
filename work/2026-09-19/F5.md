**Un-nesting the KV banks (Fix 5 #2b) was NOT done**, deliberately: the bank state is `syntax:"*"` 64-axis
strings (`--fc-k/v-S-H`), which can only travel by inheritance; a sibling bank cannot feed the attention
graph, and a `content-visibility:hidden` wrapper on an ancestor bank would lock the graph itself. The
alternative that removes the alias step entirely — per-layer *inherited* storage names `--fc-L-*` read directly by
per-layer glyph rules — is bounded by the alias cost (≈270 KB substitution per S2 ≈ 10 ms/pass ≈ 0.1 s/token) and
was not worth the risk this round. See §6.

1. **In-delay transitions are re-resolved on EVERY style update of the document, even one that does not touch
   their element or anything it inherits** (sib: 13 elements = target + the 12 banks, 104 ms). Cost is per
   transition, ≈5.7 µs each (104 ms / 18,432), independent of scope; no per-frame servicing while idle (0.0 ms/s).
   Paused animations do not have this property (sib 0.1 ms) but cost ≈0.3 µs/animation of servicing per lifecycle
   and ≈2.4 µs each when their element is restyled (37 ms / 18,432 on inh vs 95 ms for the same bytes as static —
   the animated values are not re-parsed, the static 1 KB lists are).
2. Applied to the demo at position p: the KV banks hold 12 x 48p retained transitions (4,608 at p=8) -> ≈26 ms
   added to EVERY one of the 171 style passes per token ≈ 4.5 s/token at p=8, growing ≈0.56 s/token per position —
   a large share of the measured 0.8 s/token slope (B0 baseline). The 1,538 loop-bank `--saved` latches add ≈9 ms/pass
   ≈ 1.5 s/token, the 769 head-input latches ≈4 ms/pass (≈0.7 s/token). None of this is in the byte model.
3. RSS: 18,432 transitions = +151 MB over none, +96 MB over the same values as static (≈5 KB per transition);
   paused is the same (+147 MB).
4. Cheapest latch that still holds state = the transition, but its COUNT is what matters: pack the 12 heads of a
   slot into one `*` list per kind (4 transitions per slot instead of 48 -> ≈2 ms/pass at p=8) — needs per-head
   axis tags in the operator fonts (12 dot + 12 value fonts), so a follow-up, not in this bundle. A second option
   is to drop retention where a value is re-derivable (the loop banks only need the *read* bank retained, and the
   head-input latch could be a container-query stamp).
