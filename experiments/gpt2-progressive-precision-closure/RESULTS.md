# Fixed-depth progressive-precision closure

## Decision

**Retain for a browser vertical slice.** This is the first screened output-head
direction that reduces both dynamic exact work and dependency depth by a large
factor. GPT-2-small, its checkpoint, architecture, hidden width, vocabulary,
and target q16 logits are unchanged.

The proposed graph has two dependent refinement waves:

1. global rowwise-q10 lower/upper intervals activate competitive contiguous
   token blocks;
2. rowwise-q12 intervals inside those blocks activate the remaining q16
   blocks;
3. one q16 maximum produces the final token.

It replaces a best-first cascade of up to 23 whole 256-row groups with a fixed
q10 -> q12 -> q16 path.

## Conservative 1,024-state screen

The strict screen adds 27 score buckets outward at **both** precision
transitions. Every configuration retains all 1,024 browser-realized q16 target
winners.

| Block | Static gates | Mean q12 rows | Mean q16 rows | Mean dynamic glyphs | Versus serial exact shaping |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 50,257 | 123.10 | 6.24 | 813.53 | 0.110x |
| 2 | 25,129 | 228.08 | 11.69 | 1,508.82 | 0.204x |
| **4** | **12,565** | **417.70** | **22.06** | **2,770.97** | **0.375x** |
| 8 | 6,283 | 744.04 | 39.16 | 4,934.11 | 0.669x |
| 16 | 3,142 | 1,305.41 | 74.56 | 8,727.19 | 1.183x |

The dynamic-glyph proxy uses the demonstrated transports: six glyphs for a
radix-64 two-plane q12 row and twelve glyphs for a global-q16 row. The retained
serial cascade shapes 615 q16 rows / 7,380 exact glyphs on average. Its global
q10 scan is common to both sides and excluded.

B=4 is the credible knee. It cuts the modeled dynamic shaping work by 62.5%
while requiring 12,565 block gates rather than 50,257 token gates. At the same
27-bucket allowance it uses 9,336 dynamic glyphs at p95 and 31,200 at maximum,
versus 21,504 and 70,656 for the serial exact path.

Against a one-wave q10 -> q16 closure over the **same** active B=4 blocks, the
comparison is 2,771 versus 5,012 mean dynamic glyphs, or 0.553x. This is the
relevant browser crossover question: the q12 wave saves 44.7% of dynamic
shaping but adds another global layout dependency.

## What remains unproven

This is an offline certified-set and work screen, not a browser latency result.
The browser must prove that:

- the first container-query wave can reveal q12 rows whose widths feed a
  second lower/upper reduction;
- inactive q12/q16 blocks avoid shaping cost in the full graph;
- radix-64 q12 transport stays conservative after HVAR interpolation;
- 12,565 static gates do not erase the dynamic-work gain.

The B=4, 256-token vertical slice is correct but takes 33.22 ms versus 6.37 ms
for the direct gate. That slice saves only 9% of dynamic glyphs (its q12
survivor fraction is much worse than the global corpus), so it proves the
second dependency has a roughly 27 ms local cost but does not by itself settle
the full-vocabulary crossover. A larger scaling probe must show enough avoided
q16 shaping to amortize that cost before a production graph is justified.
