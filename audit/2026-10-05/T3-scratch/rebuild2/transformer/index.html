A transformer, computed by CSS.

One GPT-2-style block, three attention heads, a 12-dimensional embedding, causal softmax attention, GELU, residual paths, and three statically unrolled autoregressive steps.

Choose a three-token prompt
␠abbcdde..␠a ␠abcde. ␠abcde. ␠abcde.

␠ab → cde
bcd → e.␠
de. → ␠ab
.␠a → bcd

The Python build step fits the tiny language head and writes static CSS. At runtime, CSS performs the transformer arithmetic, computes each max(), derives one-hot token choices with abs(sign()), and feeds the chosen embedding into the next unrolled step. There is no <script> element.
