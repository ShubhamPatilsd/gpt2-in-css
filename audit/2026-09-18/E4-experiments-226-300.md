## 2. Mechanism families

### A. GSUB glyph-identity computation (entries 227, 228, 236–243)
Substitution tables as a digital circuit: glyph identity carries state; ligatures/contextual lookups implement adders, nonlinear tables, running totals.
- Best measured: depth-16 reversible 2×4-bit cell, 6.5 ms vs 10.2 ms direct CSS per 256 outputs (only GSUB win over CSS, 31–36%). 64-input weighted sum 107.8 ms vs 22.3 ms CSS.
- Blockers: (1) joint-input tables grow `16^k` with fan-in; (2) HarfBuzz/Chrome rejects GSUB with ≥16,384 cumulative subtable references (hard validator limit, verified 16,383 vs 16,384); (3) glyph count 272N+196 hits 65,535 at N=241; (4) shaping/layout time dominates and does not track table size (fewer passes was slower); (5) shared-input matrix workloads favor HVAR 2.9x. Final reader (anchor/container) costs only 3–4 ms and is not the bottleneck.

### B. GSUB-indexed output-head scorer + certified hybrid (entries 229–235, 240)
`cv01` numeric feature selects one of 256 score rows per HVAR face; CSS margin gate falls back to exact scorer.
- Best measured: full-screen hybrid 1.62x mean (135.7 vs 220.2 ms), 0 unsafe accepts; isolated switching 21.9 ms vs 226 ms CSS dispatch (10x).
- Blockers: Chrome 32,768 px adjusted-advance cap corrupts groups 0/1 (fixed by split complement); independent 1/64 px snapping of score+complement gives ±1–3 bucket error; six-bucket certificate is empirical/Chrome-153-only; every integration into the six-stage best-first head lost (7.1–7.9 s vs 5.2–6.0 s) because the top-two certificate grid adds more layout than it removes. Lesson recorded: "the scalable optimization must remove an existing composed layout stage without adding a parallel certificate graph." `1ch`/`1ic` ignore GSUB entirely.

### C. HVAR dense matvec transport and packing (entries 226, 245–249, 252, 256–258, 263, 265, 272–274, 292, 298, 299)
- Best measured: registered-inheritance packet gather 41.8 ms for a 768-wide vector (9.6x over additive animations); packed fallback runs cut child elements 7.5x; grid/subgrid 1.9x local transport; ideal fresh-vector matrix floor ≈91 ms per MLP (two matrices).
- Blockers: 256-axis Chrome ceiling; nothing gathers N sibling geometry results into one `font-variation-settings` list (`anchor-size()`, `calc-size()`, `@function(anchor-size())` all compute to `normal`/initial); font metrics give only 5 scalars per font, so output multiplicity is linear (924 fonts / 2.83 GB for one 768×768); radix row packing impossible because HVAR cannot round before summing; TrueType outline coordinates are int16 (gvar wrap); 512-level HTML parser nesting (XHTML bypasses parser but not layout depth); `anchor-size()` unusable on in-flow boxes. Fresh (never-shaped) axis vectors cost 3–9x cached revisits — several earlier wins were cache hits.

### D. View-timeline / container-geometry packing (entries 244, 296, 297, 300, plus 268)
- Best measured: 4 values per timeline (two 8–9-bit digits per geometric degree) — packed4 block 1.005 s vs 1.851 s; 14 exact bits/coordinate ceiling (guarded-timeline-capacity), ~18 guarded bits usable.
- Blockers: multi-megapixel geometry loses mantissa (7-value/23-bit carrier RMSE 20–45; 4×17-bit container packing loses 111–210 units); per-channel/log encodings that look good offline amplify geometry error in Chrome (RMSE 1.24–1.44); −41% timelines gave only −22% latency because layout/style dependency resolution, not timeline count, dominates.

### E. Raster / SVG handoff (entries 245, 246, 255–257)
- Best measured: whole 3,072-vector export in 84.7 ms (one gvar glyph, 12 elements) or 99.95 ms (bars); QKV raster 296 ms at RMSE 0.0057.
- Blockers: one-way only (no raster→axis/number path); `feConvolveMatrix` fails above 256 taps → 9,216 convolutions for a 3072→768 row set; 8-bit product surfaces give RMSE 0.40; the next SVG stage after a filtered raster collapsed to zero.

### F. Alternative reducers and native layout arithmetic (entries 259, 267, 294–295)
- Best measured: SWAR anchor 3072→128 slice 1.40 s; inline `font-size` reducer exact but 1.3–1.66x slower than flat CSS; orthogonal `cqw×cqh` product exact.
- Blockers: O(context×width) DOM carriers; projected ~4.5 s per MLP for SWAR; orthogonal containers consume both axes so the result cannot escape for reduction.

### G. Model-side approximation (offline; entries 251, 269, 270, 271)
- Best measured (offline only): LN fusion 10-bit RMSE 0.0021/0.0102; rank-63 attention 98.2% agreement; codebooks 36% rel. error; rank-256 SVD 19.8%.
- Blocker: every one violates the frozen-checkpoint accuracy target; no browser fixture built. All rejected/shelved.

### H. Connected-graph profiling, scheduling, and the native runtime (entries 261, 262, 264, 285, 286, 287–290, 293)
- Best measured: 12 blocks in 39.3–39.7 s/fresh token (no head); exact-GELU oracle shows 26.6x ceiling if transport were free; delayed-transition value latch retains 2,304 QKV values across producer retirement (4/4); native ping-pong loop ~55 ms/pass at width 2–3; chunk-128 consumers −14–19% on isolated stages; static bank readers −9% continuation.
- Blockers: connected two blocks cost ~2x isolated sum (37k layout objects, 23k dirty per layout); 12-block connected 39.6 s vs 9.16 s isolated (30 s unattributed gap: 30% animation servicing, 27% paint/compositing); containment, `visibility:hidden`, stylesheet minification, preloading, chunking beyond 128 all neutral or worse; matched avar2 MLP candidate slower and less accurate than the native core; optimization-followups native comparisons unfinished (power/sleep interruptions).

## 4. Surprising / positive results without a successor

1. **GSUB depth-16 crossover** (gsub-arithmetic-depth-probe): the only measured case where a font-internal circuit beat direct CSS (6.5 vs 10.2 ms). No deeper depth, no wider state, and no "start at the running-total marker" dispatch (proposed in gsub-partitioned-digits/NEXT_DIRECTIONS.md) was ever built.
2. **Static product-width font** (gsub-partitioned-digits control): 10.2 ms at 64 inputs, beating HVAR 41.2 ms for one-output vectors and within 8% at 16 shared outputs — with a 720-byte font. Dismissed as "especially favorable" synthetic alphabet; no real-weight or wider-precision screen was run (2.36M product glyphs for real FC noted as the reason).
3. **Guarded timeline capacity = 14 exact bits/coordinate**, flat ~50 ms regardless of guard: never written up or fed back into the packing designs (which assume ~18 guarded bits and use 8–9-bit digits).
4. **Registered-inheritance gather 9.6x at width 768** (packed-hvar-transport-scaling) — adopted for TinyStories fixtures but the RESULTS notes the "remaining scaling costs are dense output glyphs, repeated gathers across a full block" — no 12-block GPT-2 measurement with this gather appears in this slice.
5. **Grid/subgrid 1.9x local transport + coordinatewise GELU** (grid-subgrid-vector): retained as "constant-factor", no successor attempting a grid-based gather or combining with #4.
6. **HVAR signed range / virtual base** (hvar-resulting-advance-range, hvar-virtual-base): both range facts positive; the only downstream use (one-plane hot row) lost by 1 bucket and 1.15x; the 6-glyph-vs-12-glyph row idea was not pursued further.
7. **Delayed-transition value latch** (hybrid-12block-profile/value-latch): passes 4/4 and unblocks producer retirement; the stated next gate ("repeated native rearm, then 1 MLP, 2 blocks, 12 blocks paired live-vs-retired") has no recorded run in this slice (native-reused-loop is the width-2/3 handshake only).
8. **Chunk-128 consumers −14–19% and static bank readers −9%** (optimization-followups): passed all gates, but the final native promotion comparison is unfinished.
9. **Compute-once GELU oracle 26.6x ceiling** (via hvar-vector-oracle → exact-gelu-vector-oracle): quantifies that transport, not arithmetic, is the whole gap; yet subsequent slice work (GSUB circuits, learned codes) attacked arithmetic.
10. **`opsz` automatic axis handoff** is exact and free relative to font-size (3,072 lanes 262.5 ms); cost is the anchor/container graph — nobody tested it combined with the Grid/subgrid carrier to avoid the deep container graph.

## Skepticism notes
- Cached-revisit numbers (8–11 ms multiface, 11.2/5.9 ms ideal carrier, 20 ms direct-CSS read) were repeatedly mistaken for compute; only fresh-vector numbers are reliable.
- gsub-certified-hybrid "2.2–2.6x" figures are projections from an adversarial stress mix; the direct full screen measured 1.62x mean and worse p95.
- hvar-parallel-full-mlp JSON contradicts the 311–314 ms figure cited for it elsewhere (624 ms median, correct:false).
- All 12-block numbers exclude prefill, final LN, vocabulary head, and KV append; the only complete-run evidence remains the historical 402.7 s (8 tokens) / 3,177 s (32 tokens) bundles.
